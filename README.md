# JGSDF: RECAPTURE（ブラウザ版）

陸上自衛隊の部隊を指揮して、占拠された拠点を奪還するリアルタイム戦略ゲームのブラウザ版です。
PC・スマホ（iPhone の Safari など）のブラウザで遊べます。

- 遊ぶ：https://wamasa2220-ux.github.io/jgsdf-recapture-web/
- スマホ：タップで選択・命令、なぞって範囲選択、2本指で地図の移動と拡大縮小。命令は画面下のボタンで
- 6km四方のマップは読み込みに30秒〜1分ほどかかります
